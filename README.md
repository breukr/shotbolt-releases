# Shotbolt for Mac: downloads

Signed and notarized builds of [Shotbolt](https://shotbolt.app/?utm_source=github&utm_medium=readme), a native screenshot and screen recording app for macOS 26 or later, on Apple silicon and Intel Macs.

**Get it:** [shotbolt.app/download](https://shotbolt.app/download?utm_source=github&utm_medium=readme), or with Homebrew:

    brew install --cask breukr/tap/shotbolt

The app updates itself. The source code is not public; this repository only hosts the release files.

## What it does

- One shortcut for every capture: area, window, full screen, the same area again, or on a timer.
- Mark up with arrows, text, counters, blur and pixelate, and change any mark after you save.
- History finds any screenshot by a word inside it. Text is read on your Mac.
- Copy the text or a QR code from anything on screen.
- Shotbolt Pro adds scrolling capture, screen recording and GIF with a video editor, automatic Redact, Edit Text and Translate, tables copied as rows and columns, step guides and workflows.

## Coming from another screenshot app?

On first launch Shotbolt brings over your shortcuts, save folder and after-capture actions from a previous screenshot app it recognises.
