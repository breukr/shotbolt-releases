# Shotbolt downloads

Signed and notarized builds of [Shotbolt](https://shotbolt.app), the fast, private screenshot app for Mac.

Download the latest version from [shotbolt.app/download](https://shotbolt.app/download). This repository only hosts the release files; the source code is not public.

Requires macOS 26 and a Mac with Apple silicon. Support: support@shotbolt.app
